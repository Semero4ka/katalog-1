# Каталог товаров и накладные — PWA

## Что внутри
- Статический PWA-каталог, подготовленный на основе предоставленных Excel-файлов.
- 3376 позиций из прайс-листа.
- Цены в рублях; остатки объединены по нормализованным названиям.
- Корзина с локальным резервированием остатков.
- Заказы со статусами «Новый» / «Завершён», повторное открытие накладной и удаление заказа.
- Редактируемая накладная: поставщик, покупатель, строки товаров, количество, цена, сумма, подписи, печать/PDF.
- Добавление фотографии товара через клик по миниатюре; полноразмерный просмотр.
- Импорт прайса и остатков из Excel в интерфейсе.
- Экспорт/восстановление резервной копии, включая заказы и фото.
- PWA manifest и service worker.

## Размещение на GitHub Pages
1. Создайте новый репозиторий GitHub.
2. Загрузите в корень репозитория все файлы из архива, включая `catalog.json`, `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `service-worker.js`.
3. В Settings → Pages выберите публикацию из ветки `main`, папка `/ (root)`.
4. Откройте опубликованный HTTPS-адрес. При первом запуске нужна сеть для загрузки библиотеки Excel (SheetJS с CDN); каталог после загрузки кешируется.
5. Для установки на компьютер/телефон откройте сайт в поддерживаемом браузере и выберите «Установить приложение» / «Добавить на главный экран».

## Важные ограничения этой версии
- Данные хранятся локально в браузере на одном устройстве (IndexedDB), не в GitHub. Экспортируйте резервную копию регулярно.
- Фото добавляются в браузере и включаются в резервную копию, но сами по себе не загружаются в репозиторий GitHub.
- Автоматической отправки заказов по электронной почте и прямой интеграции с 1С нет: для этого нужен адресат/формат обмена и, как правило, серверный компонент или отдельный обменный файл.
- Накладная печатается через диалог браузера; там можно выбрать «Сохранить как PDF».
- Прайс-лист содержит 3376 строк с названиями. Остатки сопоставлены по нормализованному названию; если остаток не найден или количество пустое, интерфейс показывает «Остаток не указан», а не считает его нулём.
- При импорте новой таблицы остатков значения физического остатка обновляются, но существующие резервы из корзины и заказов учитываются отдельно при вычислении доступного остатка.

## Источники исходных данных
- `Prays_17 (1).xlsx` — цены; первые 4 строки являются заголовком отчёта.
- `ostatki_17.xlsx` — остатки; первые 3 строки являются заголовком отчёта.
